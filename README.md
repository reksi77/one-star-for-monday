A single deadpan one-star review of Monday as a restaurant: one star, sat at table 4, served Saturday reheated and billed as fresh, while the waiter said, "Enjoy your week." The program writes exactly that one line to `/output/entry.txt` — no randomness, no network, byte-identical on every run.

## Run it

```sh
node main.ts
```
